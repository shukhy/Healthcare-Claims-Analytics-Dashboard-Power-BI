# 🏥 Healthcare Claims Analytics Dashboard | Power BI

## 📖 Project Overview

Healthcare organizations generate large volumes of claims data across hospitals, providers, and patients. This project transforms raw healthcare claims data into a comprehensive Business Intelligence solution that helps stakeholders monitor claim performance, provider risks, patient demographics, financial trends, and operational efficiency.

The dashboard was developed using Power BI to provide a centralized view of healthcare operations and support data-driven decision-making.

---

## 🎯 Business Problem

Healthcare administrators need answers to critical questions:

- How many claims are being processed?
- What is the overall approval rate?
- Which providers require audit attention?
- What financial trends exist between billed and paid claims?
- Which hospitals generate the highest claim amounts?
- How do member demographics influence healthcare costs?
- Are there any indicators of fraudulent activity?

Without a centralized dashboard, monitoring these metrics is difficult and time-consuming.

---

## 🚀 Solution

Developed a multi-page interactive Power BI dashboard that provides:

✅ Executive Performance Monitoring

✅ Provider Risk Analysis

✅ Member Demographic Insights

✅ Claims Trend Analysis

✅ Financial Performance Tracking

✅ Fraud Detection Monitoring

---

# 📊 Dashboard Pages

## 1️⃣ Executive Dashboard

### Key KPIs
- Total Claims
- Total Billed Amount
- Total Paid Amount
- Approval Rate
- Fraud Cases

### Visuals
- Monthly Claims Trend
- Financial Trend Analysis
- Hospital Type Distribution
- Top Hospitals by Claim Amount

### Business Value
Provides leadership with a high-level overview of healthcare claim performance and financial health.

## 2️⃣ Provider Analytics Dashboard

Helps identify high-risk providers and supports audit and fraud investigation processes.

## 3️⃣ Member Analytics Dashboard
